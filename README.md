# Hotel Project (StaySync)

Full-stack Hotel Booking Management System.

## Project Structure

```
├── backend/    # Node.js & Express API (MongoDB)
└── frontend/   # React, TypeScript, Vite, Tailwind CSS
```

## Getting Started

### 1. Backend Setup
```bash
cd backend
npm install
# Ensure you copy .env.example to .env
npm run dev   # or node server.js
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
